Security design

  • Passwords: peppered with HMAC-SHA256, then salted and hashed with scrypt (this page uses PBKDF2, because browsers have no scrypt).
  • Two-factor login: a 6-digit authenticator code; the secrets are encrypted with AES-256-GCM.
  • Roles and permissions: Admin, Manager and Receptionist, enforced by the server from a permissions table.
  • SQL injection protection: every query is parameterized.
  • Lockout and rate limiting: 5 wrong passwords lock the account for 15 minutes.
  • Audit log: every action is recorded, and database triggers block edits and deletes.
  • Deleted-data database: removed records are copied to a separate database first.
  • Backups: encrypted, sealed with a SHA-256 checksum, uploaded to the cloud by API.
  • Restore points: save and restore settings only, never guest or booking data.
